기존 EC2는 챗봇용 내부 진입점을 실행하므로 dev에 포함된 건강 분석 서비스를 호출할 경로가 없었습니다. 내부 인증을 사용하는 건강 분석 API를 추가해 Spring이 기존 연구 서비스를 재사용할 수 있게 합니다.

- 생활 영역과 검진·종합 분석 연결, 현재 업무 DB 단위 및 한국 날짜 정규화
- 내부 모델 자동 재시도 비활성화, 요청 크기 제한 및 오류 원문 비노출 유지
- 기존 챗봇 경로 및 데모 기본 동작 유지
- 검증: 내부 테스트 17개 통과. 실제 모델 품질·동시 부하는 후속 통합 검증 대상

이 변경은 FastAPI 연결 단계입니다. Spring 자정 실행·당일 캐시·DB 변경과 Android 화면은 별도 적용이며, 데모 웹 화면을 EC2 외부에 공개하지 않습니다.
