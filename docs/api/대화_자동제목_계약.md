- 첫 저장 질문을 제목으로 사용한다. 요약이 아직 없으면 다음 질문에도 첫 제목을 유지한다.
- 정상 답변과 함께 비어 있지 않은 새 누적 요약이 반환되면 요약으로 제목을 갱신한다. 제목용 AI 호출은 추가하지 않는다.
- 원문 질문과 최대 4,000자 요약은 기존 저장 구조에 보존한다. 목록 제목은 공백을 정리하고 기존 100자 한도 초과 시 끝에 …를 붙인다. 앱 목록은 한 줄 말줄임으로 표시한다.
- 제목 변경 API로 지정한 제목은 자동 갱신하지 않는다. 파트너만 변경하면 자동 갱신을 유지한다.
- 제목·메시지·요약은 동일 소유권 및 세션 잠금 아래 한 트랜잭션으로 저장한다. 실패·지연 응답·재시도는 기존 정책을 따른다. 부분 답변은 새 요약 제목으로 갱신하지 않는다.
- 공개 API의 title, 내부 API의 summary를 그대로 사용한다. FastAPI 변경·재배포는 필요 없다.
